印度尼西亚 · Bali 旅居段

B1 · 10月26日｜抵达 Bali

抵达 Canggu · KIMA Check-in

抵达后只做入住、熟悉环境和轻社交，不急着把自己塞进课程。第一晚的重点是进入 Surf Camp 氛围。

路线：DPS Airport → KIMA Surf Camp Canggu住宿：KIMA Surf Camp Canggu节奏：抵达适应

时间安排

  1. 下午抵达 Bali，前往 KIMA Surf Camp Canggu
  2. 傍晚Check-in、认识室友和营地工作人员
  3. 晚上参加集体晚餐/Drinks，有机会就主动用英语破冰

备选方案

  • 如果航班晚点，直接入住休息，把社交放到第二天早餐开始。

拍照机位

  • KIMA 公共空间生活感照片
  • Canggu 傍晚街景
  • 第一天入住房卡/冲浪板小记录

餐厅建议

  • KIMA Surf Camp Dinner：优先参加营地集体晚餐
  • Milk & Madu Canggu：轻松国际化餐厅备选
  • Crate Cafe：Canggu 社交感咖啡备选

B2 · 10月27日｜Canggu

第一次 Surf Session · Social Breakfast

第一天正式跟 KIMA 节奏走，冲浪不是为了全勤，而是用共同活动自然认识国际住客。

路线：KIMA → Canggu Beach → KIMA住宿：KIMA Surf Camp Canggu节奏：Surf + Social

时间安排

  1. 上午KIMA Surf Session，课后和同组住客聊天
  2. 中午集体早餐/午餐，交换 Instagram 或 WhatsApp
  3. 下午Pool / Rest / KIMA Gym 轻量活动
  4. 晚上参加 KIMA Social Activity 或集体晚餐

备选方案

  • 身体疲劳时跳过 Gym，优先休息和晚上的社交。

拍照机位

  • 冲浪板合照
  • 营地早餐桌
  • Canggu 日落海边剪影

餐厅建议

  • KIMA Breakfast：优先参加集体早餐
  • The Shady Shack：Canggu 健康餐备选
  • La Brisa：日落 drinks 备选

B3 · 10月28日｜Canggu

Surf · Yoga / Mobility · BBQ

第二个完整日可以开始熟悉人名和小圈子，运动后用 BBQ / Dinner 继续聊天。

路线：KIMA 生活半径住宿：KIMA Surf Camp Canggu节奏：冲浪后恢复

时间安排

  1. 上午KIMA Surf Session
  2. 下午Yoga / Mobility 按身体状态参加
  3. 傍晚Ice Bath / Recovery 或 Pool
  4. 晚上KIMA BBQ / Dinner，主动加入多人桌

备选方案

  • 如果肩颈或腰背累，取消 Yoga，只做轻拉伸和 Ice Bath。

拍照机位

  • BBQ 长桌氛围
  • 营地泳池
  • 恢复区生活记录

餐厅建议

  • KIMA BBQ：优先参加营地活动
  • Warung Local：轻松印尼饭备选
  • Penny Lane：Canggu 社交餐厅备选

B4 · 10月29日｜Canggu

Surf · Gym · Sunset Drinks

今天的目标不是多练，而是主动约人：问别人来自哪里、后面去哪、要不要一起看 sunset。

路线：KIMA → Beach → Sunset住宿：KIMA Surf Camp Canggu节奏：轻训练 + 社交

时间安排

  1. 上午KIMA Surf Session 或自由休息
  2. 下午KIMA Gym 轻量力量/核心
  3. 16:30 后Sunset Drinks，和营地朋友自由约

备选方案

  • 如果前几天冲浪累，上午直接休息，保留傍晚社交。

拍照机位

  • 海边 drinks 手持杯照
  • 日落冲浪人影
  • 朋友合照但不强迫拍

餐厅建议

  • La Brisa：Chill sunset
  • The Lawn Canggu：海边 drinks 备选
  • Mason Canggu：晚餐候选

B5 · 10月30日｜Canggu

Surf · Pool · Social Dinner

中段开始不要追求全勤，留出睡午觉、发消息约饭、和新朋友自然相处的空间。

路线：KIMA 慢节奏住宿：KIMA Surf Camp Canggu节奏：轻松社交

时间安排

  1. 上午按身体状态参加 Surf Session
  2. 下午Pool / Nap / Coffee，自由安排
  3. 晚上和 KIMA 认识的朋友吃饭

备选方案

  • 如果没人约饭，就参加营地晚餐，别为了找局焦虑。

拍照机位

  • 泳池边阅读/咖啡
  • 朋友晚餐桌面
  • Canggu 夜晚街头

餐厅建议

  • Mason Canggu：社交晚餐候选
  • Sa'Mesa Canggu：多人桌氛围强，适合认识人
  • Lila Brown：轻松晚餐备选

B6 · 10月31日｜Canggu

Surf · Recovery · Halloween Social

如果营地或 Canggu 有 Halloween 活动，可以自然加入；不是为了 party，而是练英语和认识人。

路线：KIMA → Recovery → Social住宿：KIMA Surf Camp Canggu节奏：恢复 + 活动

时间安排

  1. 上午Surf Session 或休息
  2. 下午Ice Bath / Recovery / Mobility
  3. 晚上KIMA Social / Halloween Drinks

备选方案

  • 如果不想 party，就和小群朋友吃轻松晚餐。

拍照机位

  • 活动穿搭小记录
  • 营地公共区
  • 夜晚 drinks 氛围

餐厅建议

  • KIMA Social Dinner：优先跟营地
  • Luigi's Hot Pizza：Canggu 热闹晚餐备选
  • Old Man's Bali：海边社交 drinks 备选

B7 · 11月1日｜Canggu

Surf · Café · Deep Talk

进入营地后半段，把重点放在关系沉淀：和聊得来的人约咖啡、晚餐或后续 Berawa 继续见。

路线：KIMA → Café → Sunset住宿：KIMA Surf Camp Canggu节奏：自由社交

时间安排

  1. 上午Surf Session 或自由休息
  2. 下午Café / Coworking 轻整理旅行计划
  3. 晚上和朋友 dinner / sunset

备选方案

  • 如果社交过载，下午独处，晚上再加入集体活动。

拍照机位

  • 咖啡馆桌面旅行计划
  • 朋友背影合照
  • 日落后蓝调海边

餐厅建议

  • Baked Canggu：咖啡和早午餐
  • Revolver Canggu：咖啡候选
  • Shelter Pererenan：晚餐备选

B8 · 11月2日｜Canggu

最后 Surf Camp 日 · 联系方式交换

KIMA 最后一天，重点是留下联系方式、约后续 Berawa/Umalas 见面，不需要强行补任何课程。

路线：KIMA Final Day住宿：KIMA Surf Camp Canggu节奏：收尾和告别

时间安排

  1. 上午最后一次可选 Surf Session
  2. 下午整理照片、交换 IG / WhatsApp
  3. 晚上Final Dinner / Drinks

备选方案

  • 如果身体累，直接跳过冲浪，只做告别和休息。

拍照机位

  • 冲浪营最终合照
  • 手环/板架细节
  • final dinner 桌面合照

餐厅建议

  • KIMA Final Dinner：优先参加
  • The Lawn Canggu：日落备选
  • Mason Canggu：晚餐备选

B9 · 11月3日｜Berawa / Umalas

KIMA Check-out · 新酒店入住

Surf Camp 结束后不继续安排冲浪，切换到 Tennis、Fitness、Wellness 和继续见朋友的生活节奏。

路线：KIMA → Berawa / Umalas住宿：Berawa / Umalas 私人房节奏：换酒店 + 休息

时间安排

  1. 上午KIMA Check-out
  2. 下午新酒店 Check-in、Pool / Rest
  3. 晚上和 Surf Camp 认识的朋友吃饭

备选方案

  • 如果新酒店下午才能入住，找咖啡馆等房间，不安排课程。

拍照机位

  • 新酒店泳池
  • 房间/阳台细节
  • 朋友重聚晚餐

餐厅建议

  • Milk & Madu Berawa：轻松多人餐
  • Baked Berawa：咖啡和早午餐
  • Mason Canggu：晚餐候选

B10 · 11月4日｜Berawa / Umalas

Tennis Private · AMO Recovery

第二阶段第一节 Tennis 放在上午，下午接 AMO Sauna + Ice Bath，兼顾学习和身体恢复。

路线：Hotel → Tennis Club → AMO住宿：Berawa / Umalas节奏：一个主项目 + 恢复

时间安排

  1. 上午Private Tennis Lesson 1：握拍、站位、正反手基础
  2. 下午AMO Sauna + Ice Bath / Contrast Therapy
  3. 晚上Sunset / Dinner，自由约朋友

备选方案

  • 如果 Tennis 临时约不到，把 AMO 放上午，Tennis 顺延到 11/5 或 11/8。

拍照机位

  • Tennis court 侧面挥拍
  • AMO recovery 前后对比
  • Berawa sunset

餐厅建议

  • Baked Berawa：运动后 brunch
  • Sisterfields Berawa：咖啡和轻食
  • Milu by Nook：晚餐和稻田氛围

B11 · 11月5日｜Berawa / Umalas

Group Fitness · Massage / Café

用 Group Fitness 继续认识新人和练英语，下午给按摩或咖啡馆，不把自己练废。

路线：Hotel → Fitness Studio → Café住宿：Berawa / Umalas节奏：Group Class + 下午自由

时间安排

  1. 上午Group Fitness：Strength / Functional / HYROX / Boxing 选一
  2. 下午Massage 或 Café / Coworking
  3. 晚上Social dinner，优先临时朋友局

备选方案

  • 如果肌肉酸痛，改 Mobility / Reformer Pilates。

拍照机位

  • 训练后镜子合照
  • 咖啡馆笔记本旅行计划
  • 按摩前后的恢复感

餐厅建议

  • BGS Bali Canggu：咖啡和 casual chat
  • Nude Canggu：健康餐候选

B12 · 11月6日｜Optional Diving

Tulamben 轻松 2 Dives / Rest Day

只有状态好才去 Tulamben，目标是轻松岸潜恢复手感，不追求深潜、强流或复杂 drift dive。

路线：Canggu → Tulamben → Canggu住宿：Berawa / Umalas节奏：Optional 高消耗日

时间安排

  1. 清晨Optional：出发 Tulamben
  2. 上午/中午USAT Liberty 轻松 2 dives，安全优先
  3. 下午返回 Canggu / Berawa
  4. 晚上早睡恢复

备选方案

  • 不潜水：Pool / Café / Massage / Rest Day。Nusa Penida 只有 Tulamben 状态非常好后才考虑。

拍照机位

  • 潜水装备平铺
  • Tulamben 海边岸潜入口
  • Rest Day 泳池躺平

餐厅建议

  • Hotel Breakfast：潜水前轻食
  • Tulamben Dive Resort Lunch：跟潜店安排
  • Berawa Light Dinner：回来后吃清淡

B16 · 11月10日｜Resort 转场

路线：Christchurch → Airport → Shanghai住宿：返程节奏：机场缓冲

时间安排

  1. 上午酒店退房，检查行李和租车物品
  2. 中午视航班时间还车、值机
  3. 下午/晚上基督城飞上海，通常需要中转
  4. 备选航班晚则安排市区咖啡或南极中心半日

备选方案

  • 如果航班很晚，可去 International Antarctic Centre；如果行李多，优先机场附近轻松等候。

拍照机位

  • 基督城市区最后咖啡照
  • 机场出发前合照
  • 南极中心入口打卡

餐厅建议

  • Unknown Chapter Coffee：市区咖啡候选
  • C1 Espresso：基督城经典咖啡馆候选
  • Riverside Market：返程前补餐和伴手礼
