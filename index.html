澳大利亚 · 悉尼段

S1 · 11月14日｜悉尼会合

落地购物 · 歌剧院芭蕾夜

Jessie 14:00 抵达悉尼，下午只安排轻购物和休息，晚上暂定悉尼歌剧院芭蕾，不把第一天压得太满。

路线：悉尼机场 → CBD → 歌剧院住宿：悉尼 CBD / Circular Quay 周边节奏：落地缓冲

时间安排

  1. 14:00Jessie 抵达悉尼，完成入境、取行李和会合
  2. 16:30QVB / Pitt Street Mall / Westfield Sydney 轻购物
  3. 18:00CBD 简单晚餐，尽量别离歌剧院太远
  4. 19:30暂定悉尼歌剧院芭蕾《Copland Dance Episodes》

备选方案

  • 如果落地疲惫，取消演出，只保留 Circular Quay 夜景和早休息。

拍照机位

  • 歌剧院台阶仰拍
  • Circular Quay 远景合照
  • 海港大桥夜景人像

餐厅建议

  • Bennelong：歌剧院内正式餐，适合仪式感晚餐
  • Chat Thai Circular Quay：港口附近热门泰餐，适合演出前后
  • Din Tai Fung World Square：CBD 稳定选择，适合刚落地不想冒险

S2 · 11月15日｜悉尼市区

海德公园 · 植物园 · 海港经典线

把悉尼最经典的市区景点集中在一天完成，动线顺、拍照点密集，晚上留给轻松晚餐和港口夜景。

路线：Hyde Park → St Mary’s → Art Gallery → Royal Botanic Garden → Circular Quay住宿：悉尼节奏：全天 City Walk

时间安排

  1. 09:30海德公园和圣玛丽大教堂
  2. 11:00新南威尔士美术馆短逛
  3. 13:30皇家植物园散步到 Mrs Macquarie’s Chair
  4. 16:30Circular Quay、歌剧院和海港大桥拍照

备选方案

  • 雨天把植物园压缩，增加 QVB、The Strand Arcade 或美术馆时间。

拍照机位

  • Mrs Macquarie’s Chair 拍歌剧院+海港大桥同框
  • 圣玛丽大教堂正面广角
  • 皇家植物园草坪港口背景

餐厅建议

  • The Grounds of the City：CBD 复古风 brunch，适合拍照
  • Opera Bar：歌剧院旁海港景观，适合傍晚
  • Mr. Wong：CBD 热门中餐，适合正式晚餐

S3 · 11月16日｜悉尼 → 基督城

Bondi 海岸线 · 晚飞基督城

白天按天气二选一，晚上三人一起从悉尼飞基督城，保证 11月17日新西兰 D1 能从容开始。

路线：Bondi / Taronga Zoo → Sydney Airport → Christchurch住宿：基督城节奏：半日游 + 转场

时间安排

  1. 09:30天气好走 Bondi Beach → Tamarama → Bronte 短徒步
  2. 12:30海边午餐或咖啡
  3. 15:30回酒店取行李，前往悉尼机场
  4. 晚上悉尼飞基督城，抵达后入住休息

备选方案

  • 天气一般改 Taronga Zoo 半日；如果晚航班很早，海边只去 Bondi 拍照不徒步。

拍照机位

  • Bondi Icebergs 俯拍泳池和海
  • Tamarama 观景台
  • Bronte 海边岩石和草坪

餐厅建议

  • Bills Bondi：海边 brunch 候选
  • Icebergs Dining Room：Bondi 景观餐厅，预算较高
  • Lox Stock & Barrel：Bondi 轻食咖啡

新西兰 · 南岛段

D1 · 11月17日｜基督城

纸板教堂 · 复古电车 · 雅芳河

正式开始新西兰段。今天不跨城赶路，重点是取车、熟悉右舵、逛纸板教堂和雅芳河，把自驾状态调整好。

路线：基督城市区轻松适应住宿：基督城节奏：取车补给

时间安排

  1. 09:30取车、检查车况、熟悉右舵驾驶
  2. 11:00纸板教堂和新摄政街
  3. 14:00复古电车、雅芳河、植物园
  4. 17:30超市补给，准备后续自驾早餐和路餐

备选方案

  • 如果前一晚航班延误，压缩市区，只保留纸板教堂、超市和早休息。

拍照机位

  • 纸板教堂正面几何线条
  • New Regent Street 彩色立面
  • 雅芳河桥边人像

餐厅建议

  • Riverside Market：选择多，适合多人各吃各的
  • Twenty Seven Steps：市中心评价稳定，适合晚餐
  • Little High Eatery：轻松美食广场，适合第一天

D2 · 11月18日｜基督城 → 蒂卡波湖

肉派小镇 · 牧羊人教堂 · 观星

从基督城进入中线湖区，中途吃 Fairlie Bakehouse 肉派，下午留给牧羊人教堂和湖边步道，晚上看天气安排观星。

路线：基督城 → Fairlie → Lake Tekapo住宿：蒂卡波湖节奏：约 3-3.5 小时驾驶

时间安排

  1. 08:30基督城出发
  2. 11:00Fairlie Bakehouse 肉派早餐/早午餐
  3. 13:00抵达蒂卡波湖，湖边步道和牧羊人教堂
  4. 20:30Tekapo 观星，按当天云量确认

备选方案

  • 云多或下雨改 Tekapo Springs；牧羊人教堂可放 D3 清晨补拍。

拍照机位

  • 牧羊人教堂侧面避开人流
  • 湖边鲁冰花季节性前景
  • 傍晚蓝调时间拍教堂剪影

餐厅建议

  • Fairlie Bakehouse：肉派必停，适合外带
  • Kohan Restaurant：Tekapo 热门日餐，建议预订
  • Dark Sky Diner：观星前后顺路，景观好

D3 · 11月19日｜蒂卡波 → 普卡基湖 → 库克山区域 → 特威泽尔

普卡基三文鱼 · 雪山窗口 · 冰川二选一

今天的重点是普卡基湖和库克山区域：吃 Mt Cook Alpine Salmon，在游客中心大玻璃窗拍照，再按天气二选一做冰川或徒步。

路线：Tekapo → Lake Pukaki → Aoraki 区域 → Twizel住宿：特威泽尔节奏：看项目强度调整

时间安排

  1. 09:00牧羊人教堂晨拍后离开 Tekapo
  2. 10:30Lake Pukaki Visitor Centre：三文鱼、大玻璃窗、塔尔羊雕像
  3. 12:00Peter’s Lookout 拍普卡基湖和库克山远景
  4. 13:30首选塔斯曼冰川直升机徒步；备选胡克谷步道

备选方案

  • 直升机取消且天气一般：Tasman Glacier View Track + 库克山游客中心 + 早回 Twizel。

拍照机位

  • Lake Pukaki Visitor Centre 大玻璃窗长焦人像
  • 塔尔羊雕像与湖景同框
  • Peter’s Lookout 路边雪山湖泊大景

餐厅建议

  • Mt Cook Alpine Salmon：普卡基湖三文鱼，适合外带湖边吃
  • The Old Mountaineers Cafe：库克山区域咖啡和简餐
  • Poppies Cafe Twizel：Twizel 晚餐/咖啡候选

D4 · 11月20日｜特威泽尔 → 瓦纳卡

林迪斯山口 · 孤独的树 · 湖边慢游

按照你们选择的轻松版执行：不把下午耗在重徒步上，到瓦纳卡后拍孤独的树、大树和湖边，晚上早点休息。

路线：Twizel → Omarama → Lindis Pass → Wanaka住宿：瓦纳卡节奏：约 2-2.5 小时驾驶

时间安排

  1. 09:30Twizel 出发，Omarama 短停
  2. 11:30Lindis Pass 观景点拍照
  3. 14:00抵达 Wanaka，湖边咖啡
  4. 16:00That Wanaka Tree、Wanaka Station Park 大树

备选方案

  • 如果 D3 因天气没徒步，可加 Diamond Lake / Rocky Mountain 短徒步。

拍照机位

  • 孤独的树用湖面做留白
  • Wanaka Station Park 大树低角度
  • 湖边栈道夕阳剪影

餐厅建议

  • Big Fig Wanaka：份量友好，适合自驾晚餐
  • Kika：Wanaka 高人气餐厅，适合正式晚餐
  • Federal Diner：咖啡和早午餐候选

D5 · 11月21日｜瓦纳卡 → 皇后镇

卡德罗纳 · 箭镇 · 酒庄备选

上午在瓦纳卡收尾，下午不久留，按天气选择皇冠山脉或克伦威尔酒庄线，傍晚抵达皇后镇。

路线：Wanaka → Cardrona / Cromwell → Arrowtown → Queenstown住宿：皇后镇节奏：半日转场

时间安排

  1. 09:30Wanaka 湖边咖啡，补拍孤独的树
  2. 11:00天气好走 Cardrona Hotel + Crown Range
  3. 13:30Arrowtown 小镇、华人定居点和河边散步
  4. 17:00抵达 Queenstown 入住，湖边散步

备选方案

  • 天气不好走 Cromwell + Gibbston 酒庄区；司机不试酒，只拍照、午餐或买酒。

拍照机位

  • Cardrona Hotel 门口复古车/建筑
  • Arrowtown Buckingham Street 街景
  • Crown Range 高处公路感照片

餐厅建议

  • The Chop Shop Arrowtown：Arrowtown 人气 brunch/午餐
  • Aosta Arrowtown：正式晚餐候选
  • Gibbston Valley Winery：酒庄午餐和葡萄园拍照

D6 · 11月22日｜皇后镇

跳伞 · Skyline Luge

把跳伞放在皇后镇第一天，给天气取消留改期空间。下午休息后去 Skyline Gondola + Luge，看瓦卡蒂普湖全景。

路线：Queenstown 市区 + 活动接驳住宿：皇后镇节奏：高强度项目日

时间安排

  1. 08:30跳伞集合或酒店接驳
  2. 12:30市区午餐和休息
  3. 16:00Skyline Gondola + Luge
  4. 19:30皇后镇晚餐，轻松收尾

备选方案

  • 跳伞取消顺延到 D8；当天改 Queenstown Gardens、湖边和咖啡。

拍照机位

  • Skyline 观景台俯拍湖湾
  • Luge 入口山景合照
  • Queenstown Bay 日落湖边

餐厅建议

  • Fergburger：经典热门汉堡，适合外带
  • Botswana Butchery：湖边正式餐候选
  • Flame Bar & Grill：烤肉和肋排候选

D7 · 11月23日｜皇后镇

Nevis 弹射秋千 · Shotover Jet

上午做 Nevis Catapult + Swing，下午 Shotover Jet。中间保留缓冲，避免接驳和 check-in 时间互相打架。

路线：Queenstown → Nevis → Shotover住宿：皇后镇节奏：刺激项目日

时间安排

  2. 10:00Nevis Catapult + Nevis Swing
  3. 14:30返回市区休息补给
  4. 16:30Shotover Jet 喷射快艇

备选方案

  • 任一项目取消顺延 D8；晚上可安排 Kai KikoKiko 或湖边轻松餐。

拍照机位

  • Nevis 平台出发前合照
  • Shotover Jet 河谷照片点
  • Queenstown Mall 夜景街拍

餐厅建议

  • Kai KikoKiko：你们指定的 Queenstown 餐厅，适合活动后晚餐
  • Blue Kanu：亚洲融合菜，适合多人分享
  • Tanoshi：日式小馆，适合轻松晚餐

D8 · 11月24日｜皇后镇

项目缓冲 · 温泉 · 湖边散步

这天不去 Glenorchy，专门作为跳伞、Nevis、Shotover Jet 的天气缓冲。若项目都完成，就安排温泉、花园、咖啡和购物。

路线：Queenstown 机动日住宿：皇后镇节奏：缓冲休整

  4. 19:00整理行李，准备次日去但尼丁

备选方案

拍照机位

餐厅建议

  • The Grille by Eichardt’s：湖边景观餐

D9 · 11月25日｜皇后镇 → 但尼丁

中奥塔哥转场 · 但尼丁火车站

从皇后镇横切到但尼丁，路上只做短停，下午拍但尼丁火车站，晚上安排 Little India Dunedin。

  2. 11:00Cromwell / Alexandra 咖啡短停
  3. 15:00抵达但尼丁，火车站和市区散步
  4. 18:30Little India Dunedin 晚餐

备选方案

  • 如果出发晚，放弃市区散步，只保留火车站外观和晚餐。

  • 但尼丁火车站正面广角
  • 站内马赛克地砖俯拍

D10 · 11月26日｜但尼丁 → 奥马鲁

海狮海狗 · 大圆石 · 小蓝企鹅归巢

今天是动物线：上午奥塔哥半岛/Sandfly Bay，中午北上摩拉基大圆石和卡蒂基角，晚上准时到奥马鲁看小蓝企鹅归巢。

路线：Dunedin → Otago Peninsula → Moeraki → Kātiki Point → Oamaru住宿：奥马鲁节奏：景点多，需控时

时间安排

  1. 08:30但尼丁出发，奥塔哥半岛 / Sandfly Bay
  2. 12:30北上 Moeraki Boulders
  3. 15:00Kātiki Point 看海狗、碰碰黄眼企鹅机会
  4. 傍晚抵达 Oamaru，晚餐后看小蓝企鹅归巢

备选方案

  • 如果 D10 时间紧，优先保留 Kātiki Point 和 Oamaru Penguins，Moeraki 拍照压缩到 30-40 分钟。

拍照机位

  • Moeraki Boulders 低机位大圆石
  • Kātiki Point 灯塔步道远景
  • Oamaru 企鹅中心外海岸日落

餐厅建议

  • Fleur’s Place Moeraki：海鲜名店，需确认营业和预订
  • Cucina Oamaru：Oamaru 晚餐候选
  • Scotts Brewing Co.：企鹅前轻松晚餐候选
